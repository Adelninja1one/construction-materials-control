# منظومة مواد البناء — GitHub Pages Companion

نسخة عربية ساكنة وآمنة للاستعراض من منظومة مواد البناء. تشمل أدوات القرار المحلية ودليل فريق الوكلاء، ولا تحتوي مفاتيح API أو قاعدة بيانات أو سجلات مستخدمين أو كوداً خادمياً.

## الوظائف الرئيسية

| المجال | الأدوات |
|---|---|
| الحسابات | الكلفة الواصلة، محول الوحدات، حجم الخرسانة، تقدير البلك/الياجور، وسلة مواد المشروع. |
| المواد | دليل عملي للإسمنت والحديد والركام والرمل والجبس والبلك والياجور والعوازل والإضافات. |
| المشتريات | نقطة إعادة الطلب ومخزون الأمان وتقييم المورد متعدد المعايير. |
| مركز العمليات | صفحة `operations.html` تشرح مسار السعر الموثق والأتمتة المقترحة والمراجعة البشرية، وتفصل ما لا توفره النسخة الساكنة. |
| الجودة والسلامة | قبول دفعات المواد، عدم المطابقة، تقييم الخطر، وفحص أمن المخزن ومنع الفاقد. |
| الحوكمة | توثيق مصادر البيانات، التخزين المحلي، والتصدير والاستيراد بصيغة JSON. |
| الوكلاء | صفحة `agents.html` توضح أدوار وكلاء الشراء والمخزون والجودة والسلامة والدراسة المعمقة وحدودهم المهنية. |

## التشغيل محلياً

افتح `index.html` مباشرة في متصفح حديث. لا يتطلب الموقع خادماً أو قاعدة بيانات. ويمكن فتح `agents.html` لعرض دليل الوكلاء.

## حدود الاستخدام

> هذه المنظومة أداة دعم قرار وليست بديلاً عن المخططات المعتمدة، أو تصميم الخلطات، أو نتائج المختبر، أو شهادة المطابقة، أو مسؤول السلامة، أو العقود واللوائح المحلية.

لا يجلب الموقع أسعاراً تلقائية من الإنترنت؛ يتعين إدخال السعر وتاريخه ومصدره والتحقق من الوحدة وشروط التسليم قبل اتخاذ قرار شراء.

## حدود GitHub Pages

> GitHub Pages يستضيف ملفات ثابتة فقط. لذلك لا تتوافر فيه المحادثة الخادمية عبر Gemini، أو مهام Manus الخاصة، أو تسجيل الدخول، أو قاعدة البيانات. تبقى هذه الميزات في التطبيق الخادمي الآمن، ولا يجوز نقل أسراره إلى GitHub Pages.

يحفظ مصدر التطبيق الكامل في مستودع GitHub خاص مستقل، مع استبعاد ملفات البيئة والأسرار والمخرجات المحلية.
